## Agent skills

### Issue tracker

Issues und Spezifikationen werden als GitHub Issues in `Rindula/ed-traderoutes` verwaltet. Siehe `docs/agents/issue-tracker.md`.

### Triage labels

Verwendet die Standardlabels `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human` und `wontfix`. Siehe `docs/agents/triage-labels.md`.

### Domain docs

Single-Context-Repository mit `CONTEXT.md` und `docs/adr/`. Siehe `docs/agents/domain.md`.
