# Unzugängliche Systeme aus Standardrouten ausschließen

Permit-gesperrte, nicht erreichbare oder anderweitig als unzugänglich bekannte Systeme werden nicht als Start-, Zwischen- oder Zielsystem einer Standardroute verwendet. Unklare Zugangsbedingungen gelten als nicht belastbar; eigene Berechtigungen können später als Teil des Spielerkontexts berücksichtigt werden.
